# YMB EJS差分同期ツール

EJSで管理しているサイトをビルド・公開した後、クライアントが公開済みHTMLを直接編集してしまい、EJSソースとの間に差分が生まれてしまう問題に対応するツールです。

公開後のHTMLとEJSを再ビルドした結果を比較し、

- 静的な部分(テキスト・属性・タグ追加など)の変更 → 自動的にEJSソースへ反映
- 動的な部分(`<% %>`の式やinclude絡み)の変更 → 自動反映せず、レビュー用に提示

という形でEJS側へ差分を書き戻します。

## できること / できないこと

- 対応: EJSの静的リテラル部分のテキスト・属性・タグ構造の変更
- 対応: `<%- include path %>`(括弧無しのレガシー記法)を含むinclude展開
- 対応: 公開HTMLの取得元をローカルフォルダとURL(本番サーバー等)から選択可能。Basic認証にも対応
- 未対応: `for` / `forEach` などのループ構文(現状のテンプレートに存在しないため未実装)
- 未対応: SCSSのコンパイル後CSSからSCSSソースへの自動反映(変数・ネスト・mixinの解決により安全な自動反映が困難)

## 使い方(開発モードで起動)

```bash
npm install
npm start
```

起動したら、

1. EJSソースルート、公開HTMLルートをそれぞれ選択します。一度入力したパスは記憶され、次回起動時に自動で復元されます
2. 公開HTMLの取得元は「ローカルフォルダ」と「URLから取得」を切り替えられます。URLモードではベースURL(例: `https://www.example.com/site`)を指定すると、本番サーバー上のHTMLを直接取得して比較できます。Basic認証がかかっている場合はID/パスワードを入力してください(パスワードは保存されません)
3. 対象サブディレクトリを指定(空欄で全体)
4. 「スキャン実行」
5. ページ一覧から確認したいページを選択します。一覧の幅はドラッグで調整でき、幅は記憶されます(ダブルクリックで既定幅にリセット)
6. 差分は追加=緑・削除=赤(取り消し線)の文字単位ハイライトで表示されるので、変更箇所を確認しながら適用できます
7. 自動反映可能な差分はページ単位で一括適用できるほか、ツールバーの「全ページ一括適用」で差分のある全ページの自動反映可能なパッチをまとめて適用できます。要レビューの差分は内容を確認して個別に適用します
8. パッチ適用時には自動的に `.bak` バックアップが作成され、適用後は該当ページが自動で再スキャンされて「公開HTMLと完全一致」または「残り差分N件」が表示されます。適用結果に問題があれば、バックアップからワンクリックで適用前の状態に復元できます
9. パッチカードの「エディタで開く」から、VSCodeで該当ファイル・該当行を直接開けます(`code -g` を使用。VSCode未導入の場合はフォルダ表示にフォールバックします)

## ダウンロード

[Releases](https://github.com/yumebi/ymb_ejs_synch/releases) からインストーラーをダウンロードしてください。

> **インストール時に警告が表示される場合があります。** このアプリは個人配布用で、コード署名(証明書による発行者署名)を行っていません。
> これは悪意のあるソフトという意味ではなく、署名コストをかけていない未署名アプリに対する標準的な警告です。
> - **Windows**: 「Windows によって PC が保護されました」(Microsoft Defender SmartScreen)と表示された場合、「詳細情報」→「実行」を選択してください。
> - **macOS**: 「開発元が未確認のため開けません」と表示された場合、Finderでアプリを右クリック(またはControl+クリック)→「開く」を選択してください。初回のみこの操作が必要です。
